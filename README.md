# Credit Risk & Loan Eligibility Analysis

## Project Overview

This project analyzes credit risk and loan eligibility using data analysis, SQL, Power BI, and Machine Learning. The objective is to identify important factors that influence loan approval decisions and build a predictive model for loan eligibility.

## Technologies Used

- Python
- Pandas
- NumPy
- MySQL
- SQL
- Power BI
- Machine Learning
- Scikit-learn

## Dataset

The project uses a loan application dataset containing information such as:

- Person Age
- Gender
- Education
- Annual Income
- Employment Experience
- Home Ownership
- Loan Amount
- Loan Intent
- Loan Interest Rate
- Loan Percent Income
- Credit History Length
- Credit Score
- Previous Loan Defaults
- Loan Status

## Project Workflow

1. Load and explore the loan application dataset.
2. Clean and preprocess the data using Python.
3. Store and analyze data using MySQL and SQL queries.
4. Perform exploratory data analysis to identify factors affecting loan eligibility.
5. Build a Machine Learning model for loan approval prediction.
6. Use the trained model to predict loan eligibility for new applications.
7. Create visualizations and insights using Power BI.

## Key Analysis Areas

- Loan approval and rejection distribution
- Income analysis
- Credit score analysis
- Previous default history analysis
- Employment experience analysis
- Interest rate analysis
- Credit history analysis
- Factors influencing loan eligibility

## Machine Learning

A Machine Learning model was trained to predict loan approval based on relevant applicant and loan-related features.

The project includes:

- Data preprocessing
- Feature selection
- Model training
- Loan eligibility prediction

## Project Files

- `main.py` – Main data analysis and processing workflow
- `app.py` – Application interface
- `predict_loan.py` – Loan prediction script
- `credit_risk_analysis.sql` – SQL analysis queries
- `loan_data.csv` – Dataset used for analysis

## Project Outcome

This project demonstrates an end-to-end data analytics workflow combining Python, SQL, Power BI, and Machine Learning to analyze credit risk and support better loan eligibility decisions.
